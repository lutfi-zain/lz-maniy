# Tasks

All checkboxes are implementation work, not actions authorized by proposal creation. Commands naming `check:secrets` and `test:integration` refer to scripts introduced below. Every live invocation requires the target/account permissions and private configuration in `design.md`; never print environment values. One complete authorized lifecycle run can satisfy several related acceptance checks; the repeated command is not an instruction to wipe/run separately for each checkbox. A failed numeric assertion is reported, not re-pinned or marked verified.
